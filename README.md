# DOVA

Base inicial da plataforma SaaS DOVA: tecnologia para cada empresa ter seu próprio aplicativo, com marca, operação e clientes independentes.

## Estado atual

Esta primeira entrega é somente a **casca visual e estrutural**:
- Dashboard central da plataforma.
- Navegação lateral entre módulos.
- Layout responsivo para desktop e celular.
- Identidade visual inicial e componentes básicos.
- Conteúdo de demonstração claramente fictício.

Ainda não há autenticação, banco de dados, multi-tenancy real, pedidos reais, pagamentos, notificações ou integrações.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

A aplicação usa React, TypeScript, Vite e Lucide. Nenhum serviço externo ou banco de dados é conectado nesta etapa.
